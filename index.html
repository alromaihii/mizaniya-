iOS Shortcuts Setup
Set this up once and AlSalam Bank messages auto-update your budget.
Deep Link
mizaniya://add?amount=AMOUNT&merchant=MERCHANT
Step-by-Step
1
Open Shortcuts App
Find the Shortcuts app → tap Automation at the bottom.
2
New Automation
Tap + → New Automation → choose Message as trigger.
3
Set Trigger
Sender = AlSalam Bank number. Message Contains:
debited BD
4
Get Message Body
Add action: Get Details of Messages → select Body.
5
Match Text (Regex)
Add Match Text:
BD ([0-9.]+).*?At: (.+?)\n.*Balance: BD ([0-9.]+)
6
Open Mizaniya
Add Open URLs:
mizaniya://add?amount=[Match1]&merchant=[Match2]
7
Save & Test
Save the automation. Next AlSalam SMS → tap Allow → budget updates instantly.
